# Classplus — EduLearn Platform

Monorepo containing four Flutter applications:

| App | Folder | Description |
|-----|--------|-------------|
| Student | `edulearn_student_app` | Student mobile app |
| Teacher | `edtech_teacher_app` | Teacher mobile app |
| Admin | `premium_saas_admin_dashboard_app` | Institute admin dashboard |
| Super Admin | `enterprise_super_admin_dashboard_app` | Enterprise super-admin dashboard |

## Run an app

```bash
cd edulearn_student_app   # or any app folder
flutter pub get
flutter run
```
